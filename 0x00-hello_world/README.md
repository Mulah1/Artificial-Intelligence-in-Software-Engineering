# 0x00 - Hello World

This directory contains small scripts and C programs used to learn basic compilation steps in C.

Files added:
- 0-preprocessor: Run the C preprocessor on $CFILE and save output to file named `c`.
- 1-compiler: Compile the C file $CFILE to object file (.o) without linking.
- 2-assembler: Generate assembly code from $CFILE and save to .s file.
- 3-name: Compile $CFILE and produce executable named `cisfun`.

All scripts are two lines long and start with the required shebang. They should be made executable before running the tests with `chmod u+x <script>` if needed.
